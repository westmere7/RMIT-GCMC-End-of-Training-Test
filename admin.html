Settings

Sign-in gate

Stored as SHA-256 fingerprints, so the JSON never shows the actual email or ID. Email case doesn't matter, and spaces in the ID are ignored.

Questions

Written answers ignore capitals, accents, spaces and punctuation, so “Thursday.”, “thursday” and “THURSDAY” all match. For fill-in questions, put ___ (three underscores) where the blank goes.
